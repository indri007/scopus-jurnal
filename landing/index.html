Features

Every stage of the research pipeline

Built from the actual codebase. No invented features.

📁
Repository Audit
Clones your GitHub repo, scans every file, and reconstructs the research problem, dataset, methods, and variables — classifying each statement as [DATA], [CODE], [DOCUMENTATION], or [EVIDENCE_REQUIRED].

Code

Simple Python API

agents/orchestrator.py
Python 
from agents.orchestrator import Orchestrator

# Run the full pipeline
orch = Orchestrator(progress_cb=print)

state = orch.run_pipeline(
    github_url     = "https://github.com/your/research-repo",
    topic          = "Sarcasm Detection in Indonesian Social Media",
    target_journal = "Information Processing & Management",
    citation_style = "apa",
    output_format  = "both",
)

# Or run individual slash commands
state = orch.run_command("/literature", state)
state = orch.run_command("/find-gap",   state)
state = orch.run_command("/reviewer",   state)

print(f"Output: {state.path('final')}")
Get Started

Up and running in 4 steps

1

Clone the repository

git clone https://github.com/indri007/scopus-jurnal
2

Install dependencies

pip install -r requirements.txt
3

Configure API keys

cp .env.example .env
4

Launch Streamlit UI

streamlit run app.py
